# Weekly review

Run `node scripts/herd.mjs calving-watch --json`, `node scripts/herd.mjs attention --json` and `node scripts/herd.mjs sale-readiness --json`. Follow up with compliance and animal reads for each flagged record. Write the calving plan, yard work, receipt follow-ups and sale preparation decisions to drafts/weekly-review.md. State the data time and missing evidence. Never describe a due date as a confirmed birth or an expired hold date as clearance.
